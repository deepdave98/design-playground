# Design playground

Web design and motion by Deep Dave.

[Sand clouds](designs/sand-clouds/) · [Fluid pixels](designs/fluid-pixels/) · [Wordmark distortion](designs/wordmark-distortion/)

`npm install` → `npm run dev`

Each folder in `designs/` contains its source, preview, assets, and usage notes. Tests live beside the design they cover.

`npm test` · `npm run build` → `dist/` for Vercel.
